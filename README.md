# NEO Tracker

A web app that tracks Near-Earth Objects using NASA's open API, with a simple space-themed interface.

Live: [Add your GitHub Pages link here]

## About

Pulls real-time data from NASA's NEO API and displays information about asteroids and objects passing close to Earth — size, distance, velocity, and approach dates.

## Features

- Real-time data from NASA's NEO API
- Space-themed interface
- Displays object size, distance, and approach date
- Simple, readable layout for browsing multiple objects

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- NASA NEO API
- Hosted on GitHub Pages

## API Key

This project uses NASA's public API. Get a free key at api.nasa.gov and add it in script.js where indicated.
